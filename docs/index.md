## Keeping claims accurate

Before describing a feature, security control, test result, or deployment as implemented, verify it in the current source and identify the revision reviewed. Mark assumptions and operational details that cannot be verified from public source. The deployment and recovery page distinguishes checked-in configuration from unverified production claims.
